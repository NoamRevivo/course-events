שיתוף לקבוצת הוואטסאפ ופרסום חי

איך שולחים לקבוצת הוואטסאפ?
ברגע שהאתר מפורסם בכתובת אינטרנט (למשל דרך GitHub Pages, Netlify או Vercel), כל מה שצריך לעשות הוא לשלוח את הקישור לקבוצת הוואטסאפ של הקורס.

איך כולם רואים את העדכונים בזמן אמת?
כשאתה נכנס עם סיסמת המנהל ומעדכן אירוע, שעה או הודעה נעוצה, הנתונים נשמרים בענן ומתעדכנים אוטומטית אצל כל מי שנכנס לקישור (ואם אין חיבור ענן פעיל, נשמרת גרסה מקומית בדפדפן).

הגדרת סנכרון ענן חי לכולם

עדכונים אוטומטיים לכל הסטודנטים שנכנסים לקישור הקבוע

איך מחברים ב-2 דקות (חינם לגמרי):

  1. היכנס ל-console.firebase.google.com וצור פרויקט חדש.
  2. הפעל Firestore Database (במצב Production עם כללי אבטחה) ו-Authentication → Anonymous.
  3. בהגדרות הפרויקט הוסף אפליקציית Web והעתק את אובייקט ה-firebaseConfig לכאן, או הדבק אותו ישירות בקבוע DEFAULT_FIREBASE_CONFIG שבקוד כדי שיעבוד לכולם מיד!
